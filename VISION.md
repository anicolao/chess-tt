# Tabletop Chess Vision

Our goal is to create a simple, elegant chess game designed specifically for tabletop form factors. This is intended for large touchscreen tables where players are physically seated opposite each other.

## Core Pillars

1. **Physical Presence**: The game should feel like a physical board. It should not be cluttered with UI elements that distract from the game.
2. **Touch First**: Every interaction must be designed for touch. Pieces should be easy to grab, drag, and drop. Large, clear targets are a must.
3. **Symmetry**: The UI must accommodate two players facing each other. This might mean redundant controls or UI elements that are oriented for each player.
4. **Simplicity**: No complex menu systems. Just chess. Start, move, reset.

## Target Experience

A user walks up to a touchscreen table, sees a chess board, and immediately knows how to start a game with the person across from them. The experience is seamless, lag-free, and visually stunning in its minimalism.
